-----------------------------------------------------------------------
1. PRERREQUISITOS DEL SISTEMA
-----------------------------------------------------------------------
Antes de comenzar la instalación, asegúrese de contar con las siguientes
herramientas globales instaladas y configuradas en su sistema operativo
(ej. Arch Linux / Windows CLI):

* Docker Desktop o Docker Engine (v26.x o superior)
* Docker Compose CLI
* Cliente Git (configurado con credenciales globales)

-----------------------------------------------------------------------
2. PASOS PARA LA INSTALACIÓN Y DESPLIEGUE LOCAL
-----------------------------------------------------------------------

Paso 2.1: Clonación del repositorio de gestión
Abra la interfaz de línea de comandos (CLI) de su sistema y clone el
repositorio exclusivo de la materia:
$ git clone https://github.com/tu-usuario/HerramientasdeGestion.git
$ cd HerramientasdeGestion

Paso 2.2: Configuración de variables de entorno (.env)
Para garantizar la comunicación aislada y segura de los contenedores, 
cree un archivo de configuración en la raíz del directorio "/backend":
$ nano backend/.env

Agregue las siguientes líneas y guarde el archivo (Ctrl+O, Enter, Ctrl+X):
PORT=3000
MONGO_URI=mongodb://root:secret@db:27017/retiscan?authSource=admin
JWT_SECRET=ClaveSeguraMateriaGestion2026
FLASK_IA_URL=http://ia-engine:5000

Paso 2.3: Construcción de imágenes y contenedores
Ejecute Docker Compose para descargar las dependencias de Node.js, empaquetar
el entorno de Python para el procesamiento de IA y levantar los servicios:
$ docker compose up --build -d

Paso 2.4: Verificación del estado operativo (Health Check)
Compruebe que los microservicios estén conectados de forma interna realizando
una petición HTTP de diagnóstico a la API:
$ curl http://localhost:3000/health

Respuesta exitosa esperada del servidor:
{"status": "UP", "database": "CONNECTED", "ia_engine": "ONLINE"}
