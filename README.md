## Descripción del Proyecto Fusionado
Este repositorio aloja la documentación de gestión para el desarrollo de un ecosistema digital unificado que integra las tecnologías de **RetiScan** y **Vocaciones-STEAM**. 

Se trata de una **Aplicación Web Progresiva (PWA)** diseñada bajo una **arquitectura por capas**, estructurada en dos módulos principales de alto impacto social y tecnológico:

1. **Módulo de Diagnóstico Clínico (RetiScan):** Sistema automatizado enfocado en brindar screening y detección temprana de afectaciones médicas (como la retinopatía diabética) mediante el procesamiento asíncrono de imágenes empleando modelos avanzados de Inteligencia Artificial (redes neuronales convolucionales).
2. **Módulo de Orientación e Inclusión (Vocaciones-STEAM):** Una plataforma inteligente orientada a guiar y potenciar el desarrollo técnico-profesional de los usuarios. Utiliza algoritmos de Inteligencia Artificial para el análisis de perfiles e intereses, combinados con herramientas de **geolocalización** para ubicar de forma estratégica centros de salud, laboratorios de investigación, universidades y ofertas académicas del ecosistema STEAM en tiempo real.

---

## Arquitectura Tecnológica General
El sistema híbrido saca provecho de un stack moderno y homogéneo encapsulado en contenedores de infraestructura:
* **Frontend:** Aplicación Web Progresiva (PWA) desarrollada con el SDK de Flutter.
* **Backend Core:** API RESTful robusta programada en Node.js con Express, encargada de la lógica de negocio, seguridad (JWT) y persistencia en PostgreSQL.
* **Motor Analítico (IA):** Microservicio asíncrono construido en Python con Flask para la ejecución de los pipelines de Inteligencia Artificial.
* **Infraestructura:** Despliegue, aislamiento y orquestación local completa administrada mediante Docker y Docker Compose.
